# Data availability

The source repository does not contain raw imzML/ibd files, SCiLS Lab projects,
or the 3,100 exported training ion images because these are large research-data
assets rather than source code.

The [published article](https://doi.org/10.1016/j.foodchem.2026.151138)
states: "The data will be made available on request."
For data-access enquiries, contact the corresponding author, Aibo Wu,
at [abwu@sinh.ac.cn](mailto:abwu@sinh.ac.cn).

Shared data should preserve filenames referenced by `../manifests`, include
SHA-256 checksums, and state the SCiLS Lab export/normalization settings.
The release manifests use the manuscript-correct day labels (14 dpi and 17
dpi), so a public image archive must use those corrected filenames as well.
